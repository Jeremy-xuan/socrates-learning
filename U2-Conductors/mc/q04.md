# Q4

Two wires made of the same material have the same length but different radii. When the same potential difference is applied across both wires, which wire has the greater current?

(A) The wire with the larger radius
(B) The wire with the smaller radius
(C) Both wires have the same current
(D) Cannot be determined without more information

---

**Answer: (A)**

From Ohm's law: I = V/R, and R = ρL/A = ρL/(πr²)

For the same V and L, the wire with larger radius r has smaller resistance R, and therefore greater current I.
