# Q30

The current density J in a conductor is related to the electric field E by which of the following? (σ is conductivity)

(A) J = σ/E
(B) J = σE
(C) J = E/σ
(D) J = σ²E

---

**Answer: (B)**

Ohm's law in microscopic form:
$$\vec{J} = \sigma \vec{E}$$

This is equivalent to J = E/ρ where ρ is resistivity.
