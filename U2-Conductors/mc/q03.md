# Q3

A cylindrical wire of radius R carries a current I with uniform current density. Which of the following expressions gives the current density J?

(A) J = I/πR²
(B) J = I/2πR
(C) J = IR²
(D) J = I²/πR

---

**Answer: (A)**

Current density J is defined as current per unit cross-sectional area. For a cylindrical wire with radius R:
$$J = \frac{I}{A} = \frac{I}{\pi R^2}$$
