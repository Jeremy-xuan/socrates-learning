## 核心公式

### 电流
$$I = \frac{q}{t}$$
$$I = nqSv$$

### 电阻
$$R = \frac{U}{I}$$
$$R = \rho \frac{L}{S}$$

### 闭合电路
$$I = \frac{E}{R + r}$$
$$U = E - Ir$$

### 电功与电功率
$$W = UIt$$
$$P = UI = I^2R$$

### 焦耳定律
$$Q = I^2Rt$$
