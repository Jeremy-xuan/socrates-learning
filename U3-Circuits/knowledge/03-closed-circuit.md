# 3.3 闭合电路

## 闭合电路欧姆定律

**内容**：闭合电路中的电流与电源的电动势成正比，与电路的总电阻成反比。

$$I = \frac{E}{R + r}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $I$ | 电路中的电流 | A |
| $E$ | 电源电动势 | V |
| $R$ | 外电阻（负载电阻） | Ω |
| $r$ | 电源内电阻 | Ω |

## 电动势

- **定义**：非静电力把单位正电荷从负极移到正极所做的功
- **物理意义**：表示电源把其他形式的能转化为电能的能力
- **单位**：伏特（V）
- **表达式**：$E = \frac{W}{q}$

## 路端电压

$$U = IR = E - Ir$$

| 外电阻变化 | 电流 I | 路端电压 U | 内电压 Ur |
|------------|--------|------------|-----------|
| 增大 | 减小 | 增大 | 减小 |
| 减小 | 增大 | 减小 | 增大 |

**特殊状态**：
- **断开**（R→∞）：I=0，U = E
- **短路**（R→0）：I = E/r（很大），U = 0

## 功率关系

### 电源功率
- **总功率**：$P_{总} = EI$
- **输出功率**：$P_{输出} = UI$
- **内耗功率**：$P_{内} = I^2r$

### 功率分配
$$P_{总} = P_{输出} + P_{内}$$

### 电源效率
$$\eta = \frac{P_{输出}}{P_{总}} = \frac{R}{R + r}$$

## 串并联电路

### 串联电路特点
- 电流：$I = I_1 = I_2 = ...$
- 电压：$U = U_1 + U_2 + ...$
- 电阻：$R = R_1 + R_2 + ...$
- 功率：$P = P_1 + P_2 + ...$

### 并联电路特点
- 电压：$U = U_1 = U_2 = ...$
- 电流：$I = I_1 + I_2 + ...$
- 电阻：$\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + ...$
- 功率：$P = P_1 + P_2 + ...$
