# 带电粒子在磁场中的运动——例题解析

## 例题1：电子在磁场中的偏转

**题目**：一电子以速度v = 10^7 m/s垂直射入B = 0.1T的匀强磁场中，求电子运动的轨道半径。（电子质量m = 9.1×10^-31 kg）

**分析**：
- 电子电荷e = 1.6×10^-19 C
- 垂直射入磁场，洛伦兹力提供向心力
- $evB = \frac{mv^2}{r}$

**解答**：
$$r = \frac{mv}{eB} = \frac{9.1 \times 10^{-31} \times 10^7}{1.6 \times 10^{-19} \times 0.1} = 5.7 \times 10^{-4} \text{ m}$$

**答案**：半径约为0.57 mm

## 例题2：回旋加速器原理

**题目**：说明回旋加速器的工作原理。

**分析**：
- 利用磁场使粒子做圆周运动
- 利用电场加速粒子
- 粒子在磁场中运动周期与速度无关

**原理**：
- 粒子在磁场中做匀速圆周运动，T = 2πm/qB
- 在两个D形盒缝隙处加交变电场
- 电场周期与粒子运动周期相同
- 粒子每经过缝隙加速一次
- 半径逐渐增大
