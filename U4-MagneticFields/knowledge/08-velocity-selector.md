# 电磁组合场——例题解析

## 例题：速度选择器

**题目**：如图所示为速度选择器原理图。匀强电场E = 10^4 V/m，匀强磁场B = 0.1T，两者相互垂直。一束带电粒子以不同速度水平向右飞入，求能飞出的粒子的速度大小。

**分析**：
- 带电粒子受电场力：$F_E = qE$（方向向上或向下，取决于电荷正负）
- 带电粒子受洛伦兹力：$f = qvB$（方向与电场力相反）
- 只有当两力平衡时，粒子做匀速直线运动

**解答**：
- 能飞出的粒子满足：$qE = qvB$
- 所以：$v = \frac{E}{B} = \frac{10^4}{0.1} = 10^5$ m/s

**答案**：v = 10^5 m/s

**关键点**：
- 速度选择器选择的是**特定速度**的粒子
- 与电荷量、电荷正负无关
- 速度大于E/B的粒子向上偏
- 速度小于E/B的粒子向下偏
