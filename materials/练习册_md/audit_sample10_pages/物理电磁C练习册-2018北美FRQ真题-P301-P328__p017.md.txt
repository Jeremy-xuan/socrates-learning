**(b)** Use Gauss’s law to derive an expression for the magnitude of the electric field in the following regions.

$r < a$

|--------------------------------------------------------------------------|---------|
| $\frac{q_{\text{enc}}}{\varepsilon_0} = \oint \vec{E} \cdot d\vec{A}$ |         |
| $\frac{q(r)}{\varepsilon_0} = E A_{\text{sphere}} = E \left(4\pi r^2\right)$ |         |
| For correctly substituting the charge from part (a)(i) into the equation above | 1 point |
| $\frac{\beta \pi r^4}{\varepsilon_0} = E \left(4\pi r^2\right)$ |         |
| $E = \frac{\beta r^2}{4\varepsilon_0}$ |         |

$a < r < b$
