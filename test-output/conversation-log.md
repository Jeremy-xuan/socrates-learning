```markdown
# Chapter 21: Electric Fields

## 核心概念
1. 电场定义：E = F/q₀（单位电荷受到的力）
2. 电场方向：正电荷受力方向
3. 点电荷电场：E = kQ/r²
4. 电场叠加原理：E⃗_total = E⃗₁ + E⃗₂ + ...

## 关键知识点
- 电场是矢量，有大小和方向
- 电场存在于电荷周围的空间，与是否有检验电荷无关
- 电场线：从正电荷出发，终止于负电荷
```

### 【教学对话正文】

**紅莉栖：** *用指尖敲了两下桌面* 你学过万有引力，对吧。两个有质量的物体之间有引力——这个你没问题。

那我问你：如果把其中一个物体拿走，剩下那个物体周围，还有什么吗？

**主公：** 没有了吧？引力需要两个物体才能产生。

**紅莉栖：** *把头发拨到耳后* 力确实需要两个物体。但我问的不是力。我问的是那个空间。

**主公：** ……空间？空间里什么都没有啊。

**紅莉栖：** 你确定？你家附近有没有 WiFi 信号？

**主公：** 有。

**紅莉栖：** 你看得见吗？

**主公：** 看不见。

**紅莉栖：** *靠在椅背上* 但它在。那换一个——你把一块磁铁放在桌上，然后离开房间。房间里没有人，没有其他磁铁。那个磁铁周围的空间，和没有磁铁时一样吗？

**主公：** 不一样，因为磁场还在。

**紅莉栖：** 对。那如果换成一个电荷呢？

**主公：** ……也有一个场？

**紅莉栖：** *嘴角动了一下但没笑出来* 你说说看，这个场描述的是什么。

**主公：** 就是……如果有另一个电荷放进来，它会感受到的力？

**紅莉栖：** 接近了。但你说的是"如果放进来"——也就是说，这个场在没有第二个电荷的时候也存在。对吗？

**主公：** 对。

**紅莉栖：** 好。那它描述的不是力，是什么？

**主公：** ……空间的某种性质？

**紅莉栖：** *把咖啡杯推到一边，身体前倾* 嗯。用自己的话说完整一点。——别看我，自己想。
